# Milestone 2: Workspace Expansion & Module Suite

## Objective

Expand the company workspace with core operational modules: Documents, Employees, Partners, Vehicles, and Banking.

---

## Key Deliverables

- [ ] **Documents Module:** Document upload pipeline (Multer), file previews (Images, PDF viewer), download, replace, and deletion workflows.
- [ ] **Employee Module:** Employee directory, designation, contact info, status management.
- [ ] **Partner Module:** Partner records, ownership percentage validation (max 100% total allocation).
- [ ] **Vehicle Module:** Vehicle registration, insurance details, automated expiration status indicators.
- [ ] **Banking Module:** Bank account records (IBAN, Swift), attachment handling for statements/verification files.

---

## Success Criteria

- Documents up to 25MB can be uploaded, previewed, and managed within each company workspace.
- Workspace data (Employees, Partners, Vehicles, Banking) is completely isolated per company.
