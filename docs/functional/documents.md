# 5. Documents Module

---

## Upload Document

### Supported Formats

- PDF
- PNG
- JPG
- JPEG
- DOC
- DOCX
- XLS
- XLSX
- PPT
- PPTX
- TXT
- ZIP

---

### Maximum Size

25MB

---

### Metadata

Every upload stores:

- File Name
- Original Name
- Category
- Size
- MIME Type
- Upload Date
- Uploaded By
- Company ID

---

### Workflow

Click Upload

↓

Choose File

↓

Validate

↓

Upload

↓

Store Metadata

↓

Generate Preview

↓

Display Success

---

## Preview

- **Images:** Display directly.
- **PDF:** Embedded Viewer.
- **Office Files:** Download or preview if supported.
