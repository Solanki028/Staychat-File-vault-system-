# API Specification

## REST API Standards

All endpoints adhere to standard REST conventions, using JSON for payload delivery and standard HTTP status codes.

---

## Standard Base Endpoints

- `/api/v1/auth` - Authentication & token management
- `/api/v1/companies` - Company management
- `/api/v1/companies/:companyId/workspace` - Company Workspace overview
- `/api/v1/documents` - Document management
- `/api/v1/employees` - Employee management
- `/api/v1/partners` - Partner management
- `/api/v1/vehicles` - Vehicle tracking
- `/api/v1/bank` - Banking records
- `/api/v1/invoices` - Invoices & Estimates
- `/api/v1/users` - User management & profile
- `/api/v1/search` - Global debounced search
- `/api/v1/notifications` - User & system notifications
